# Lumora — Island & Dock for Windows

Lumora (Lumen + Aura) adalah island dan dock kaca yang ringan untuk Windows 10/11, dibangun native dengan Rust, tanpa WebView dan tanpa Electron.

Bukan editor foto, bukan tool AI prompt, dan bukan platform trading. Lumora di repo ini khusus untuk: island di atas layar, dock di bawah layar, multi-monitor, Game Mode, waktu sholat, dan cuaca.
